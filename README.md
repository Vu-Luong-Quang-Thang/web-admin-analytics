# TrọƠi Web Admin Statistics

Web Admin nội bộ tổng hợp số liệu Landing Page, Mobile App, tài khoản, thanh toán và marketing của hệ thống TrọƠi.

## Trạng thái

Dự án đang ở giai đoạn chốt yêu cầu. Nhánh `root/docs` là nguồn tài liệu để cả nhóm review trước khi viết code.

## Tài liệu

- `docs/mvp-scope.md`: phạm vi và tiêu chí nghiệm thu.
- `docs/statistics-definitions.md`: định nghĩa KPI và các quyết định cần chốt.
- `docs/statistics-api-contract.md`: hợp đồng Summary API cho frontend/backend.
- `docs/team-plan.md`: phân chia công việc cho bốn thành viên.
- `docs/data-sources.md`: nguồn dữ liệu và giới hạn của GA4, Firebase, Store, Backend và Meta.

## Repository liên quan

- `TroOi-Project`: Backend NestJS và PostgreSQL.
- `TroOi-Landing-Page`: gắn GA4, UTM và sự kiện click tải app.
